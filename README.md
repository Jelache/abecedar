# Abecedarul meu

Aplicație pentru copii care învață alfabetul românesc: literele, sunetele și primele cuvinte.

**Deschide aplicația:** https://jelache.github.io/abecedar/

## Ce conține
- **Alfabet**: cele 31 de litere ale alfabetului românesc. Vocalele sunt roșii și consoanele albastre, ca în abecedarul de la școală.
- **Cuvinte**: peste 80 de cuvinte cu imagini, citite întregi, pe silabe sau literă cu literă.
- **Joacă**: trei jocuri cu stele (ascultă litera, prima literă a cuvântului, litera mare și litera mică).
- **Scrie**: scris cu degetul peste litera punctată, pe liniile caietului tip I.
- **Voce naturală**: 281 de înregistrări în limba română (litere, cuvinte, silabe, laude).
- **Funcționează fără internet** după prima deschidere și se poate instala pe ecranul telefonului.

## Instalare pe telefon
- **Android (Chrome):** meniul ⋮ → „Instalează aplicația”.
- **iPhone / iPad (Safari):** butonul Partajare → „Adaugă pe ecranul principal”.

## Fișiere
| Fișier | Rol |
|---|---|
| `index.html` | aplicația (interfață, jocuri, logică) |
| `audio.json` | înregistrările vocale, în format MP3 codat base64 |
| `sw.js` | păstrează aplicația pe dispozitiv pentru folosire fără internet |
| `manifest.webmanifest`, `icons/` | numele și iconița aplicației instalate |
| `privacy.html` | politica de confidențialitate |
